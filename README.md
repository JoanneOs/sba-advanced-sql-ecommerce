# SBA 400 - Advanced SQL E-Commerce Project

## About This Project

This is my SQL project for the SBA 400 assessment. I worked with an e-commerce database to practice SQL concepts such as indexes, constraints, triggers, views, and queries.

The project helped me understand how to manage data, connect tables, and retrieve useful information from a database.

## Tools Used

- MySQL
- SQL
- GitHub

## What I Worked On

**1. Indexes**
- Created indexes to help improve search performance.

**2. Constraints**
- Added primary keys and foreign keys to connect tables.
- Used a CHECK constraint to make sure product prices are greater than zero.

**3. Triggers**
- Created triggers to update order totals when items are added or changed.
- Created a table and trigger to track customer address changes.

**4. Views**
- Created a view to display customer orders and their details.

**5. SQL Queries**
- Found the top 3 customers based on total spending.
- Found the most popular product category based on quantity sold.

**6. View Management**
- Created a view using multiple tables.
- Updated the view to include more information.
- Deleted the view using DROP VIEW.
